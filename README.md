## 개요

이 시뮬레이터는 64명의 플레이어가 자동으로 ZE 맵을 플레이하는 과정을 시뮬레이션합니다.

**특징:**
- 완전 자동화된 64명 플레이어 시뮬레이션
- 3개의 완성된 맵 (공장/신전/감옥)
- 실시간 이벤트 로그 출력
- 감염/트롤/낙사 등 모든 ZE 이벤트 재현

## 기능

### 플레이어 시스템
- **인간 스탯**: 사격 정확도, 이동/점프 능력, 판단력, 용기, 팀워크, 유틸 사용 능력
- **좀비 스탯**: 내구력, 감염력, 이동/점프 능력, 공격성, 집단 협력 능력
- **특성 시스템**: 팀 리더, 점프 달인, 암살자형 등 12가지 특성

### 환경 보정치
- 넓은 지형
- 좁은 복도
- 낭떠러지
- 최종 홀딩
- 침수 지형 (감옥 전용)
- 함정 복도 (신전 전용)

### 핵심 공식
- **감염 확률**: 좀비의 공격력 vs 인간의 방어력
- **트롤 사고**: 팀워크, 판단력 기반 계산
- **낙사 확률**: 이동 능력, 판단력 기반 계산

## 설치 및 실행

### 요구사항
- Python 3.8 이상

### 실행 방법

```bash
# 프로젝트 디렉토리로 이동
cd cl_test1

# 실행
python3 main.py
```

### 메뉴

```
1. ZE_공장 탈출 (난이도: 중간)
2. ZE_고대 신전 탈출 (난이도: 상급)
3. ZE_지하 감옥 탈출 (난이도: 중상급)
4. 모든 맵 순차 실행
0. 종료
```

## 게임 시스템

### 페이즈 타입

| 타입 | 설명 | 특징 |
|------|------|------|
| DEFEND | 디펜스 - 일정 시간 버티기 | 사격 중심, 감염↑ |
| RUN | 런 - 좀비에게 쫓기며 이동 | 뒤쳐짐·트롤↑ |
| JUMP | 점프 - 점프맵 구간 | 낙사↑ |
| HOLD | 홀딩 - 최종 방어 | 협공/돌진↑ |

### 이벤트

- **감염**: 좀비가 인간을 감염시킴
- **트롤 사고**: 길막, 밀침, 연쇄끼임
- **낙사**: 점프 실패로 추락
- **함정**: 화살, 낙석 등 (신전)
- **침수**: 물에 빠짐 (감옥)

## 맵 정보

### 1. ZE_공장 탈출
- **난이도**: 중간
- **페이즈**: 4개
- **특징**: 넓은 창고 → 좁은 복도 → 컨베이어 점프 → 화물열차 홀딩

### 2. ZE_고대 신전 탈출
- **난이도**: 상급
- **페이즈**: 4개
- **특징**: 석상 디펜스 → 함정 복도 → 발판 점프 → 신전 입구 홀딩
- **특수**: 함정 피격 즉사

### 3. ZE_지하 감옥 탈출
- **난이도**: 중상급
- **페이즈**: 4개
- **특징**: 감옥 정문 → 철창 복도 → 침수 지하도 → 옥상 헬기 홀딩
- **특수**: 침수 지형 (이동 속도 -25%)
